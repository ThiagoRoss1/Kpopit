Rounded meta chip for counts and status that sit beside a primary action.

```jsx
<Pill>40 stickers</Pill>
<Pill>73% complete</Pill>
<Pill tone="ink">LV.2</Pill>
```

- Put the label inside the value ("40 stickers", never "Stickers: 40").
- paper (default) / pink / ink. Night paper pill goes transparent with a 10% white border.
