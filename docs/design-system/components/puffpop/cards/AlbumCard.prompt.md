Puff Pop album tile: same shell as IdolCard, vinyl cover that slides out and spins on hover, pink year sticker, light sweep, JP/EN release tag. Puff Pop (default style).

```jsx
<AlbumCard index={1} name="ANTIFRAGILE" artist="LE SSERAFIM" type="Mini" year={2022} img="https://cdn.kpopit.net/images/albums/antifragile.webp" />
```

Covers: `https://cdn.kpopit.net/images/albums/<slug>.webp`. The "sticker" and "jewel" cover variants from AlbumsForm are alternatives, not built.

Wrap pages in `<div className="pp-page" data-theme="day|night">` — it sets the dot ground and the container for responsive rules.
