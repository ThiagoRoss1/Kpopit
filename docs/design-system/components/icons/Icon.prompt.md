Inline lucide stroke icon (2.5–3 stroke, currentColor) for UI chrome — close, stats, search, arrows, lock, theme toggles.

```jsx
<Icon name="chart" size={22} />
<IconButton variant="round" label="Close"><Icon name="x" /></IconButton>
```

- Names: x, chart, arrow-right, arrow-left, search, lock, play, book, copy, sun, moon, sliders.
- For filled glyphs (trophy, fire streak, ranking, social marks) use the SVG files in `assets/icons/` via `<img>` instead.
