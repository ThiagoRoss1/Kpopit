Raised ink-outlined surface with a solid offset shadow — the base of every card, modal and box.

```jsx
<Panel variant="feature">…collection row…</Panel>
<Panel variant="sunken"><ProgressBar value={73} /></Panel>
```

- Separation is by border + offset, never by blurry shadow.
- Night: card borders drop to 10% white; feature uses the diffuse night offset; paper gets the pink border + pink 6px offset.
