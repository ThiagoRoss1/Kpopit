## Re-export checklist
`_ds_bundle.js` and `_ds_manifest.json` are generated by the design tool but were **hand-edited** during the repo cleanup. A re-export overwrites them, so repeat this after every export:

- [ ] `_ds_bundle.js` — Puff Pop UI kit data: drop the `LOCAL` list and the `local:` album prefix so every `img` is a CDN URL (`https://cdn.kpopit.net/images/idols/<id>.webp`, `.../albums/<slug>.webp`)
- [ ] `_ds_bundle.js` — web-app UI kit data: `const IMG = "https://cdn.kpopit.net/images/";` (not `../../assets/images/`)
- [ ] `_ds_bundle.js` — nav logo: `logos/kpopit-icon-svg.svg` (not `kpopit-k-logo.svg`)
- [ ] `_ds_manifest.json` — every entry in `fonts[]` has `"files": []` (fonts come from Google Fonts, no local TTFs)
- [ ] `tokens/fonts.css` — still the Google Fonts `@import`, no `@font-face` pointing at `../fonts/`
- [ ] Specimens / sources — no paths into `assets/images/` or `fonts/`; delete those folders and `uploads/` if the export recreates them
- [ ] SVGs in `assets/` — strip `<metadata><c2pa:manifest>…</metadata>` and `xmlns:c2pa`
- [ ] Check: `grep -rn "assets/images\|\.\./fonts/\|\.ttf\|kpopit-k-logo\|c2pa" docs/design-system/` returns nothing (binary textures/PNG excepted)
