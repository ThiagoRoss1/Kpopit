Filled SVG glyphs the app ships (Phosphor-style "-fill" set plus a few lucide exports and social marks). Most are single-ink: white (#ffffff) for use on neon-pink or ink, or #242424 / #b43777 for use on light grounds. `fire-fill-gray` is the inactive streak state. `twitter-white` and `x-logo-small-victory` are the white versions for dark cards. Display them with `<img>`. They cannot inherit `currentColor`, so pick the file whose ink suits the ground.
